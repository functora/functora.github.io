# Functora Egui Demo

Functora Egui Demo is the showcase application for [functora-egui](https://crates.io/crates/functora-egui), the shadcn/ui-inspired widget library for [egui](https://github.com/emilk/egui). It exercises every widget family, layout, overlay and platform capability the library ships, so the library can be evaluated in a running app instead of through documentation alone.

The demo covers:

- **Layouts**: center, flex, shell, responsive breakpoints and spacing scales
- **Forms**: inputs, textareas, selects, comboboxes, checkboxes, radios, switches, sliders and OTP fields
- **Data display**: tables, pagination, avatars, area charts, calendars, carousels and code snippets
- **Overlays**: dialogs, alert dialogs, drawers, popovers, tooltips, context menus, toasts and blocking overlays
- **Platform**: clipboard, file picking, camera capture, QR scanning, downloads, markdown rendering, thumbnails, archives and encryption

## Running

```sh
# from this crate's directory (there is no rust/ workspace)
cargo run
# web (wasm)
cargo build --target wasm32-unknown-unknown
# android via `cargo ndk` + gradle (see `android/` generated by build.rs)
# desktop Linux AppImage, from rust/ inside nix develop
release-desktop-functora-egui-demo
```
