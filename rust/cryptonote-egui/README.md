# Cryptonote-egui

Cryptonote-egui is the [egui](https://github.com/emilk/egui) edition of [Cryptonote](../cryptonote) - a cross-platform, fully offline application for creating, storing, and sharing encrypted notes. It is completely serverless and runs entirely on your device or in your web browser - no internet connection or external services are required.

With Cryptonote, you can:

- Write a note in Markdown or HTML
- Optionally encrypt it using strong, well-established algorithms (e.g., AES-GCM or ChaCha20-Poly1305)
- Or leave it unencrypted
- Share the note instantly via a URL or a scannable QR code
- Attach files to your note and pack everything into a secure offline archive (.cryptonote)

Note content - whether ciphertext or plaintext - is embedded directly in the URL itself, making sharing as simple as sending a link or displaying a QR code. Notes with attachments are packaged into an archive file that you download and share separately.

Cryptonote follows modern cryptographic best practices:

- Strong password-based key derivation with Argon2id
- Authenticated encryption for confidentiality, integrity, and authenticity
- No data ever leaves your device unless you explicitly choose to share it

Secure, private, and truly offline - your notes remain yours alone.

The Cryptonote interface is fully internationalized and currently supports English, Spanish, and Russian.

## Architecture

This crate mirrors `cryptonote` (dioxus) but is built on `functora-egui` the same way `cryptonote` is built on `functora-dioxus`:

- **Widgets**: shadcn/ui-inspired `functora-egui` components (`Button`, `Input`, `Textarea`, `Select`, `Card`, `Alert`, `Progress`, `QrScanner`, etc.) with light/dark theming and responsive mobile/desktop layouts
- **Routing**: `Screen` enum implements `Routable` + `RouteMetadata` with `AppRouter<Screen, ()>` and `NavHistory`, breadcrumbs, and deep-link handling
- **Screens**: `Home` (create/open/scan), `Open` (decrypt), `View` (rendered note + attachments), `Share` (QR + URL or archive download), `File` (preview), `About`/`Donate`/`License`/`Privacy`
- **Platform**: `functora-egui` abstractions for `clipboard`, `share`, `download`, `files` (pick/cancel/progress), `storage` (persistent theme/language), `deep_link`, `camera`/`qr`, `progress`/`worker`

## Running

```sh
cargo run -p cryptonote-egui
# web (wasm)
cargo build -p cryptonote-egui --target wasm32-unknown-unknown
# android via `cargo ndk` + gradle (see `android/` generated by build.rs)
```
