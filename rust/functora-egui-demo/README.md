# Functora Egui Demo

Functora Egui Demo is the showcase application for [functora-egui](https://crates.io/crates/functora-egui), the shadcn/ui-inspired widget library for [egui](https://github.com/emilk/egui). It exercises every widget family, layout, overlay and platform capability the library ships, so the library can be evaluated in a running app instead of through documentation alone.

The demo covers:

- **Layouts**: center, flex, shell, responsive breakpoints and spacing scales
- **Forms**: inputs, textareas, selects, comboboxes, checkboxes, radios, switches, sliders and OTP fields
- **Data display**: tables, pagination, avatars, area charts, calendars, carousels and code snippets
- **Overlays**: dialogs, alert dialogs, drawers, popovers, tooltips, context menus, toasts and blocking overlays
- **Platform**: clipboard, file picking, camera capture, QR scanning, downloads, markdown rendering, thumbnails, archives and encryption

## Running

```sh
# from this crate's directory (there is no rust/ workspace)
cargo run
# web (wasm)
cargo build --target wasm32-unknown-unknown
# android via `cargo ndk` + gradle (see `android/` generated by build.rs)
# desktop Linux release bundle, from rust/ inside nix develop
release-desktop-functora-egui-demo
```

## Nix distribution

```sh
# Local repository flake (run from rust/)
nix run .#functora-egui-demo

# Remote flake
nix run github:functora/functora.github.io?dir=rust#functora-egui-demo
```

For a standalone Linux bundle, use the repository's pinned ARX bundler:

```sh
# Requires Nix 2.34 or newer and the nix-command/flakes features
nix --extra-experimental-features "nix-command flakes" bundle \
  --bundler .# \
  .#functora-egui-demo

# Copy the standalone artifact for distribution
cp -L functora-egui-demo functora-egui-demo-v0.2.1-x86_64-linux.arx

# Or build the bundle derivation directly
nix build .#functora-egui-demo-bundle
```

`release-desktop-functora-egui-demo`, available from the `rust/` development shell, creates the same artifact under `target/desktop-release/`. The bundle includes a pinned Mesa graphics runtime with its own EGL and GLX vendor manifests, so it does not depend on host Mesa packages or graphics environment overrides. `nix bundle` is experimental and Linux-only. ARX bundles do not require FUSE, but they do require Linux unprivileged user namespaces.

**Strongly recommended:** run the demo in a fully offline [Nixpak](https://github.com/nixpak/nixpak) sandbox using the repository's [`bubble.nix`](https://github.com/functora/functora.github.io/blob/master/nix/bubble.nix) pattern to restrict filesystem access and isolate execution.
