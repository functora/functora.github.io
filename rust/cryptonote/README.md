# Cryptonote

Cryptonote is a cross-platform application for creating, storing, and sharing encrypted notes. It has no backend and no account: all cryptography runs on your device or in your browser, and nothing is stored anywhere.

With Cryptonote, you can:

- Write a note in Markdown
- Optionally encrypt it using strong, well-established algorithms (e.g., AES-GCM or ChaCha20-Poly1305)
- Or leave it unencrypted
- Share the note instantly via a URL or a scannable QR code
- Attach files to your note and pack everything into an offline archive (.cryptonote)

Note content - whether ciphertext or plaintext - is embedded directly in the URL itself, making sharing as simple as sending a link or displaying a QR code. Notes with attachments are packaged into an archive file that you download and share separately.

Cryptonote uses modern cryptographic primitives:

- Password-based key derivation with Argon2id
- Authenticated encryption for confidentiality and integrity against tampering
- Nothing is stored anywhere, and no data leaves your device unless you explicitly choose to share it

Limits worth knowing:

- Cryptonote does not prove authorship. Authenticated encryption detects tampering, not a forged author.
- A shared link is the note: everyone it reaches can open it. In the web build the note rides inside the URL, so the browser address, the history and anything else that handles URLs can see it. Plain mode puts the note text in the clear, so everyone who gets the link reads it directly.
- A shared link reveals the ciphertext, so a weak password can be cracked offline. Cryptonote warns about short passwords but never blocks the share.
- Copying text to the clipboard and exporting an unencrypted archive expose the note to other software on the device.

The full threat model and the guarantees Cryptonote makes are described in [SECURITY.md](SECURITY.md), with translations in [SECURITY.es.md](SECURITY.es.md) and [SECURITY.ru.md](SECURITY.ru.md). The same document is readable in the app, on the **Security** screen, which the about text links to.

The Cryptonote interface is fully internationalized and currently supports English, Spanish, and Russian.

## Architecture

This crate is built on [egui](https://github.com/emilk/egui) with [functora-egui](../functora-egui):

- **Widgets**: shadcn/ui-inspired `functora-egui` components (`Button`, `Input`, `Textarea`, `Select`, `Card`, `Alert`, `Progress`, `QrScanner`, etc.) with light/dark theming and responsive mobile/desktop layouts
- **Routing**: `Screen` enum implements `Routable` + `RouteMetadata` with `AppRouter<Screen, ()>` and `NavHistory`, breadcrumbs, and deep-link handling
- **Screens**: `Home` (create/open/scan), `Open` (decrypt), `View` (rendered note + attachments), `Share` (QR + URL or archive download), `File` (preview), `About`/`Security`/`Donate`/`License`/`Privacy`
- **Platform**: `functora-egui` abstractions for `clipboard`, `share`, `download`, `files` (pick/cancel/progress), `storage` (persistent theme/language), `deep_link`, `camera`/`qr`, `progress`/`worker`

## Running

```sh
# from this crate's directory (there is no rust/ workspace)
cargo run
# web (wasm)
cargo build --target wasm32-unknown-unknown
# android via `cargo ndk` + gradle (see `android/` generated by build.rs)
# desktop Linux release bundle, from rust/ inside nix develop
release-desktop-cryptonote
```

## Nix distribution

```sh
# Local repository flake (run from rust/)
nix run .#cryptonote

# Remote flake
nix run github:functora/functora.github.io?dir=rust#cryptonote
```

For a standalone Linux bundle, use the repository's pinned ARX bundler:

```sh
# Requires Nix 2.34 or newer and the nix-command/flakes features
nix --extra-experimental-features "nix-command flakes" bundle \
  --bundler .# \
  .#cryptonote

# Copy the standalone artifact for distribution
cp -L cryptonote cryptonote-v0.2.2-x86_64-linux.arx

# Or build the bundle derivation directly
nix build .#cryptonote-bundle
```

`release-desktop-cryptonote`, available from the `rust/` development shell, creates the same artifact under `target/desktop-release/`. The bundle includes a pinned Mesa graphics runtime with its own EGL and GLX vendor manifests, so it does not depend on host Mesa packages or graphics environment overrides. `nix bundle` is experimental and Linux-only. ARX bundles do not require FUSE, but they do require Linux unprivileged user namespaces.

**Strongly recommended:** run Cryptonote in a fully offline [Nixpak](https://github.com/nixpak/nixpak) sandbox using the repository's [`bubble.nix`](https://github.com/functora/functora.github.io/blob/master/nix/bubble.nix) pattern to restrict filesystem access and isolate execution.
